### Solution-to-Poisson-and-Laplace-PDEs-with-Brownian-Motion

Feynman-Kac formula presented a bridge from partial differential equations to stochastic processed. Stating that the solution to a backward, parabolic, partial differential equation (PDE) can be represented as a conditional expectation of a stochastic process. 
This code aims to exemplify the validity and strength of the formula. I tested it on three geometries: circle, square, and flower; however, more geometries and boundary conditions can be defined. It is my intention to generalize the code a bit further to allow any user to run it by merely stating the geometry and boundary conditions as arguments on a funtion. 

The final_project.ipynb file holds the code to generate all of the necessary outputs, such as animations, plots and dataframes. It also has a brief description of the folders of this project and their contents.
All of the animations and data are stored in the PLOTS and DATA folders, respectively.
